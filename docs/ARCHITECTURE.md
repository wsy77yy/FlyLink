# FlyLink 飞链 — 项目架构设计

## 1. 产品定位

FlyLink（飞链）是面向低空经济的无人机飞手供需匹配综合服务平台，打通：

- **次结商单**（滴滴式即时派单）
- **长期岗位招聘**
- **无人机设备租赁**

解决飞手接单难、企业招人难、设备租借繁琐三大行业痛点。

## 2. 用户角色

| 角色 | 代码 | 能力概要 |
|------|------|----------|
| 需求企业方 | `enterprise` | 发单、验收结算、发布岗位、租赁设备、评价飞手 |
| 个人飞手 | `pilot` | 抢单/接指派、作业上传、投递简历、互评企业、租赁设备 |
| 平台管理员 | `admin` | 用户审核、订单监管、指派订单、设备台账、中介费/抽成配置 |

## 3. 技术架构（前后端分离）

```
┌─────────────────┐     REST/JSON      ┌──────────────────┐
│  Vue3 + Element │ ◄────────────────► │  Django + DRF    │
│  Plus 前端 SPA  │   JWT Auth         │  业务 API 层     │
└─────────────────┘                    └────────┬─────────┘
                                                │ ORM
                                       ┌────────▼─────────┐
                                       │  MySQL 8.x       │
                                       │  (本地可 SQLite) │
                                       └──────────────────┘
```

### 前端

- Vue 3 + Vite + Vue Router + Pinia
- Element Plus（二次主题定制：深空蓝 + 淡青）
- Axios 请求封装
- 响应式布局（PC / Mobile）
- 页面过渡动画、毛玻璃弹窗、自定义滚动条

### 后端

- Python 3.10+ / Django 4.2 + Django REST Framework
- JWT 认证（djangorestframework-simplejwt）
- django-cors-headers 跨域
- 本地默认 SQLite，生产切换 MySQL
- View 只负责 HTTP 编排；写业务进入 `services.py`，读查询进入 `selectors.py`
- 角色权限集中在 `apps/common/permissions.py`
- OpenAPI 3 + Swagger UI 自动文档
- JSON 结构化日志与 `X-Request-ID` 请求追踪

### 后端分层

```
HTTP request
    ↓
View / Serializer（协议、输入校验、响应）
    ↓
Service（事务、状态迁移、跨模型写操作）
    ↓
Selector（可见范围、关联预取、聚合）
    ↓
Model / Database constraints
```

订单匹配在一次查询中聚合飞手历史评分，并批量写入匹配日志，查询数量不再随
候选飞手数量线性增长。

## 4. 三大核心模块业务流程

### 模块一：次结商单（滴滴模式）

```
企业发单 → LBS 智能匹配推送 → 飞手抢单/平台指派
  → 飞行计划一键申报 → 实地作业(GPS/素材)
  → 甲方验收 → 平台担保结算(抽成) → 双向评价
```

### 模块二：长期岗位招聘

```
企业发岗 → 飞手简历 → AI 双向匹配推荐
  → IM 沟通/面试邀约 → 电子签约归档 → 入职后中介费结算
```

### 模块三：设备租赁

```
货架选机 → 支付押金/信用免押 → 选租期 → 自提/物流
  → 强制绑定保险 → 归还核验 → 押金退回/扣维修费
  → 后台台账(库存/维保/折旧/租借历史)
```

## 5. 关键设计原则（前端）

- 主色：深空蓝 `#0A1628` / `#0F2744`
- 辅色：科技灰 `#E8EEF5`
- 高亮：淡青 `#00D4C8`
- 大屏风首页数据卡片 + 轻量动效
- 卡片化业务列表、分步表单、步骤条租赁流程
- 拒绝紫色渐变 / 暖奶油风 / 报纸风等 AI 默认审美
