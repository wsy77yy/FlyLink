# FlyLink 路演二维码使用说明

页面右下角新增了“路演二维码”入口，用户端和管理员端均可使用。

## 放入 PPT

1. 先将 FlyLink 部署到手机可访问的地址，或让演示电脑和手机连接同一个 Wi-Fi。
2. 打开希望评委扫码后看到的具体页面。
3. 点击右下角“路演二维码”。
4. 确认“演示网页地址”：
   - 公网部署时，默认的当前地址可以直接使用；
   - 本地路演时，将 `127.0.0.1` 改成启动日志中的 `LAN_URL` 地址；
   - 如果页面需要登录，建议二维码指向登录页，并在 PPT 上同时标注演示账号。
5. 点击“重新生成”，再点击“下载二维码”。
6. 将下载的 `FlyLink-路演二维码.gif` 插入 PPT，并在正式路演前用手机实测一次。

## 访问条件

- `127.0.0.1` 和 `localhost` 只代表当前电脑，手机无法通过它们访问；弹窗会对此给出黄色提示。
- 局域网演示要求手机和电脑在同一网络中，且防火墙允许访问 FlyLink 使用的端口（默认 `8000`）。
- 最稳定的路演方案是提前部署 HTTPS 公网地址；二维码会自动使用当前页面的完整 URL。
- 二维码在浏览器内本地生成，不会把演示地址提交给第三方二维码服务。
